# Query feature (`apps/portal/src/features/query/`)

Part of the component inventory (`INDEX.md`, beside this file, is the router).
Public surface only — the code is the source of truth; verify signatures before relying on them.


Public barrel: `features/query/index.ts`. The Athena query **workspace** — its editor, tabs, history, saved queries and results UI.

> The Glue reader, the Athena start/poll/results/cancel layer, the space list, the column-width store and their types/constants/keys are **`features/catalog/`** since SPEC-176 — see `catalog-feature.md`. The `.sql` store (the service, the space memory, the pager, `useSaveQuery` and `SaveQueryDialog`) is **`features/saved-queries/`** since SPEC-177 — see `saved-queries-feature.md`; only `SavedQueriesPanel`, this workspace's own rail surface, stayed. This feature composes both; it may not be imported by `features/data-explorer/`, and may not import it (ESLint layering rule).

### Hooks, keys, types, constants

| Symbol | File | Purpose |
|---|---|---|
| `useEditorSplit(username \| null, containerHeight)` | `useEditorSplit.ts` | The draggable editor/results split (SPEC-209): the fraction (per-user `sessionStorage`, degrade-safe, default even, written on pointer release), the editor pane's derived px height, `dividerProps` — the separator's role, ARIA value and pointer/arrow/`Home`/`End`/double-click handlers — and `step(-1 | 1)`, the one definition of a step, shared by the arrow keys and the divider's buttons. `clampEditorHeight`, `clampFraction` and `splitBounds` exported; the pixel floors are the only clamp on a measured column, and `splitBounds`'s hard fractions are what an unmeasured one reports. |
| `useQueryHistory(username \| null)` | `useQueryHistory.ts` | History list + `appendEntry`/`updateEntry` mutations (cache-seeding). |
| `buildSqlCompletions`, `createSqlCompletionProvider` | `sqlCompletions.ts` | Pure, Monaco-free builder mapping `DatabaseSchema[]` (per-DB tables) → completion descriptors: **fully-qualified** `database.table` for tables/views, bare de-duped columns with type detail; plus the Monaco provider factory reading a live `schemaRef`. | `deriveViewTargetDatabase(body)`, `schemaChangingDatabase(sql)` | `query.sql.ts` | Pure SQL heuristics: the single database of a view body's fully-qualified base tables (error when ambiguous/none), and the target DB of a schema-changing DDL statement — both used now that there's no active database (SPEC-077). |

| `useResultsPageSize(username)`, `clampPageSize(n)` | `useResultsPageSize.ts` | Workspace-global "Rows per page" value (default 100, clamped 1–1000), per-user sessionStorage persistence (defensive read, degrade-safe); `clampPageSize` is the pure validator (null for non-integers) (SPEC-087). |
