title: "Structured-logging pipe (SPEC-127→129)"
description: "Every control-plane function logs through the FIFO logs queue, swept on a 10-minute schedule into one ETag-CAS-appended JSONL object per service-day under a `logs/` prefix retained forever; `LOGS_QUEUE_URL` stays optional so a function without it logs to stdout."
---

The pipe every control-plane function logs through; it carried **boundaries only** until SPEC-130 added the narrative half ([its entry](structured-logging-narrative-primitives-and-the-one-door-rule.md)). `log-foundry` (pinned **exactly**, core not `[aws]`) ships in the `cpcommon` layer. `LOGS_QUEUE_URL` is **optional** (`environ.get`, never `_require`) so a function missing it logs to stdout instead of crashing a whole plane at cold start. The logs queue is **FIFO** (SPEC-129; it was standard until `log-foundry` gained the ability to set `MessageGroupId`), with `message_group_id` = the **event's own `log_id`** — **not the service**, which SPEC-129 chose and which saturated the sweep on 2026-09-10 (*The logs queue is grouped per event*, below) — with **no** content-based dedup (the library mints UUID dedup ids), and it is **swept** on a 10-min schedule, never long-polled (#270/#271). `service` = the **control plane**, and it is untrusted input on an S3 key: anything failing `^[a-z][a-z0-9-]{2,62}$` goes to `logs/service=_unrouted/`. Layout is `logs/service={s}/year=/month=/day=/{s}_logs_{y}_{m}_{d}.jsonl` — **one appended object per service-day**, so every write is an **ETag-CAS read-modify-write** (a failed read must never overwrite a day) and the sweep role can **read** `logs/*`, reversing SPEC-127 FR-006. The basename repeats the service and date so a copy taken out of its prefix still says what it holds, less the unrouted partition's leading underscore (`unrouted_logs_…`), because Athena treats a file whose name starts with `_` or `.` as hidden. A partition written before that name holds `data.jsonl`: the history was **not renamed**, by user decision (2026-09-27). Such a partition can gain the new file as well — the day the rename deployed does, and so does any earlier day whose late or redelivered events are swept after it — and since delivery is at-least-once, one event can sit in both files. A reader of those partitions lists the prefix rather than fetching a name, and collapses on `log_id`. Delivery is put-then-delete (at-least-once; duplicates collapse on `log_id`). Partitions come from the **event's** timestamp — except an unrouted body's, which the sweep cannot read, so it takes the sweep's clock. `logs/` is retained **forever**. `@traced` goes **outermost, above `@notifies_on_failure`**, or failed invocations close their span as `ok`. One run = **one trace** since SPEC-225 on the success path and SPEC-227 on the failure path (the API mints the traceparent and `traced` adopts it over five event shapes). The exception SPEC-227 recorded is **closed by SPEC-228 and is no longer a limit**: a failure whose error replaced the state has no traceparent on the state, and none an ASL intrinsic may reach — that much was and is true — but the forwarded envelope is on the state as `raw`, so `notify-failure` reads both the traceparent and the caller's `requestId` out of it in Python. Before that it **correlated on nothing at all**, because the seed supplies `requestId: null` on seven of the eight planes and none at all on the eighth; that was measured on archive 2026-09-09 and is what the repair was derived from. The `request_id` join stated everywhere else in this file now holds on every path. "Pre-identity" names the CATCH shape rather than the absence of an identity: all eight validators Catch `States.ALL` to that seed, so every failure raised **in the validator** lands there whatever the verb knew by then — an authorized actor's refused space included. (A failure raised downstream has its own plane's post-identity seed; archive alone has eighteen such Catches.) A refusal RETURNED as a value does not land there either: shared-spaces' `Route` sends `$.refusal` to `RefusedSeed`, one of **six** returned-refusal seeds across the fleet, and all six carry `traceparent.$`.
