Responsive breakpoint designs

Three responsive layouts for every surface, built on the existing design system and only the features shipped today. Frames are shown at true pixel width — pan and zoom the canvas to inspect. Each frame is annotated with the Tailwind v4 classes to reach it. Mobile is optimized for file management; the Query workspace is pared to a read / run experience.

Mobile < 768px

Base styles (no prefix). Single column, off-canvas nav drawer, tables become cards.

Tablet md · 768px+

The 248px rail returns, primary tabs show, tables regain columns. Reflowed toolbars.

Desktop lg · 1300px+

The current app, unchanged. Full shell with rail, drawers, and dense data tables.
